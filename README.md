# Lärmwächter

Schallpegelmesser im Browser: misst über das Mikrofon den Pegel in dB(A) und schlägt Alarm (Ton, Vibration, rote Anzeige), wenn eine einstellbare Schwelle überschritten wird.

- Live: https://farshis.github.io/laermwaechter/
- Alles läuft lokal im Browser, es werden keine Audiodaten gespeichert oder übertragen.
- Handy-Mikrofone sind keine geeichten Messgeräte; über „Kalibrierung“ mit einem Referenzgerät abgleichen.
